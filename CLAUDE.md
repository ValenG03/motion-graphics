# Motion graphics con Remotion

- Explicale al usuario cada paso en español y en términos simples.
- Para cualquier tarea de video usá las skills de Remotion en `.claude/skills/` (empezá por `remotion-best-practices`).
- Abrí la vista previa con `npm run dev` y exportá videos con `npx remotion render` (salen en `out/`, que no se sube a git).
- Al terminar cada cambio, hacé commit y push para que no se pierda.
